# TV Recorder 1.0

Приложение для записи экрана на Android TV.

- Название: **TV Recorder**
- Пакет: `tv.simple.recorder`
- Версия: `1.0` (versionCode 2)
- Android 8.0+ (API 26): Android TV / Google TV, а также телефоны и планшеты. Интерфейс подстраивается под размер экрана (на ТВ и планшетах крупнее, на телефоне компактнее), управление работает и пультом, и касанием.

## Как собрать APK через GitHub

1. Создайте новый репозиторий на GitHub и загрузите в него **всё содержимое** этой папки, включая скрытую папку `.github`.
   Через терминал:
   ```bash
   git init
   git add .
   git commit -m "TV Recorder 1.0"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/<репозиторий>.git
   git push -u origin main
   ```
2. Откройте вкладку **Actions**. Сборка `Build APK` запустится сама после загрузки (или нажмите **Run workflow**).
3. Когда сборка станет зелёной, откройте её и скачайте файл из раздела **Artifacts**: `TV-Recorder-1.0` (внутри `TV-Recorder-1.0.apk`).
4. По желанию: если отправить тег вида `v1.0` (`git tag v1.0 && git push origin v1.0`), APK появится ещё и в разделе **Releases**.

## Как установить на телевизор

- Через ADB: `adb connect <IP-телевизора>` и `adb install TV-Recorder-1.0.apk`
- Либо положите APK на флешку или отправьте через любое приложение для передачи файлов и откройте его файловым менеджером (нужно разрешить установку из неизвестных источников).
- Подпись. Ключ подписи лежит в репозитории (`app/debug.keystore`), поэтому все следующие сборки ставятся поверх предыдущей без удаления. Если Android пишет о конфликте подписи, значит, на устройстве стоит сборка, сделанная до этого изменения: один раз удалите старую версию и поставьте новую.

## Как пользоваться

1. Откройте TV Recorder. На главном экране две кнопки: **Запись** и **Настройки**. Сразу при открытии на экране появляется плавающий значок (при первом запуске Android предложит разрешение «Поверх других окон»).
2. Начать запись можно двумя способами:
   - кнопкой **Запись** в приложении;
   - значком на экране: вернитесь «Домой» или откройте любое приложение, нажмите на значок и выберите **Запись**. Системный запрос на захват экрана появится прямо поверх текущего экрана, и запись начнётся с него, без возврата в TV Recorder.
3. Запись начинается сразу после подтверждения запроса. Остановить её или поставить на паузу можно значком, кнопками в уведомлении или в приложении (на главном экране будут **Остановить запись** и **Пауза**). Файл сохранится в выбранную папку (по умолчанию `Download`), имя вида `TV_Recorder_20261125_134512.mp4`.

### Плавающий значок

Небольшая плашка поверх всех приложений. Она живёт отдельно от записи и остаётся на экране после остановки, чтобы можно было начать следующую запись.

| Состояние | Что видно | Что раскрывается по нажатию |
|---|---|---|
| Готов | серая точка и «Готов» | **Запись** и **Скрыть** |
| Запись | красная точка и таймер | **Пауза** и **Стоп** |
| Пауза | жёлтая пауза и таймер | **Продолжить** и **Стоп** |

Кнопки сами прячутся через 4 секунды. Значок можно перетащить в любое место, положение запоминается. Время паузы в видео не попадает. Скрытый значок снова появляется при следующем открытии приложения.

- Значок помечен флагом `FLAG_SECURE`, поэтому система не включает его в запись экрана: пользователь его видит, а в видео его нет. На некоторых устройствах это может работать иначе. Если значок всё же попал в кадр, выключите его в настройках или перетащите за пределы выбранной зоны.
- Без разрешения «Поверх других окон» значка не будет, а запись, пауза и остановка остаются доступными из приложения и из уведомления.
- Выключается в **Настройки → Плавающий значок**.
- Значок управляется касанием или мышью. Пультом до него не добраться, поэтому на ТВ с пультом используйте кнопки в приложении и в уведомлении. На части ТВ экрана с разрешением «Поверх других окон» нет совсем, тогда значок недоступен.
- Пока значок на экране, Android показывает постоянное уведомление службы (его можно свернуть, в нём есть кнопка **Скрыть**).

### Настройки

| Пункт | Варианты |
|---|---|
| Язык | Русский, English |
| Тема | Тёмная, Светлая |
| Место сохранения | Download (по умолчанию), Movies, DCIM или любая папка через системный выбор |
| Частота кадров | 15, 24, 30, 60, 120 |
| Область записи | Весь экран или выделенная зона |
| Плавающий значок | Включён (по умолчанию) или Выключен |

**Выделенная зона.** После выбора этого режима открывается полноэкранный экран с рамкой.
- На ТВ: стрелки двигают рамку; кнопка **OK** переключает режим «перемещение» / «изменение размера» (в режиме изменения стрелки тянут правый нижний угол).
- На телефоне и планшете: рамку двигают пальцем, за кружок в правом нижнем углу меняют размер.
- **Назад** сохраняет зону. Зона хранится в долях экрана, поэтому не зависит от разрешения.

## Ограничения версии 1.0

- Записывается только изображение, **без звука**.
- Кодировщик подбирается автоматически: сначала все H.264-кодировщики устройства с разными размерами, частотой и настройками, затем H.265, затем системный MediaRecorder. Если ничего не подошло, приложение покажет «No suitable video encoder» с перечнем причин по каждому кодировщику: пришлите этот текст, и по нему можно будет сделать точную правку.
- Защищённый контент (Netflix, YouTube Premium и подобные приложения с DRM) в записи будет чёрным, это ограничение Android.
- Максимальный размер видео 1920×1080: на 4K-экранах картинка уменьшается, иначе многие кодировщики не справляются.
- Если выбранная частота кадров или размер не поддерживаются кодировщиком, приложение само снижает сначала размер (до ~720p), затем частоту (120 → 60 → 30 → 24 → 15).
- 120 кадров/с реально получаются только на устройствах, у которых сам экран работает на 120 Гц и кодировщик это тянет. На обычном ТВ с экраном 60 Гц кадров в записи не будет больше 60, даже если выбрано 120.
- На некоторых прошивках телевизоров нет системного окна запроса на захват экрана. Тогда приложение покажет сообщение, что захват не поддерживается, и запись невозможна.
- Если выбранная папка недоступна, файл сохраняется в папку приложения (`Android/data/tv.simple.recorder/files/Movies`), и приложение об этом сообщит.

## Структура проекта

```
app/src/main/java/tv/simple/recorder/
  MainActivity          главный экран (Запись / Настройки)
  SettingsActivity      настройки
  RegionPickerActivity  выбор зоны записи (+ RegionView)
  RecorderService       foreground-сервис записи (MediaProjection)
  ScreenEncoder         общая часть и подбор кодировщика
  CodecEncoder          MediaCodec (H.264 / H.265) + запись в MP4, пауза
  RecorderEncoder       запасной путь через системный MediaRecorder
  BubbleService         служба плавающего значка (живёт отдельно от записи)
  OverlayController     сам значок: запись, пауза, стоп, перетаскивание
  CaptureActivity       невидимый экран: разрешения, запрос на захват, запуск записи
  RegionRenderer        вырезание зоны через OpenGL ES
  OutputTarget          открытие файла в Download / Movies / DCIM / выбранной папке
  Prefs, LocaleHelper, BaseActivity, RecorderState   вспомогательные классы
```

Сборка: Gradle 8.9, Android Gradle Plugin 8.7.3, JDK 17, compileSdk 35. Внешних библиотек нет.
APK подписывается открытым debug-ключом из репозитория, этого достаточно для установки вручную (для публикации в магазинах нужен собственный ключ).

Размеры интерфейса лежат в `app/src/main/res/values/dimens.xml` (телефон) и `values-sw480dp/dimens.xml` (ТВ и планшеты).
